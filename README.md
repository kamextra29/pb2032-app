# PB 2032

PWA hors-ligne (Android terrain / Windows bureau) d'identification de branchements GRDF PB 2032 : import du fichier Excel client, fiches consultables/éditables avec listes déroulantes et calculs automatiques, photos compressées renommées, export Excel « chirurgical » strictement conforme, réimport avec fusion.

## Tests

```powershell
npm test
```

## Serveur de dev

Racine du projet servie sur le port **8743** (config `pb2032` dans `.claude/launch.json`).
